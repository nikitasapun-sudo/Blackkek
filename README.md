# Blackjack Omega II — учебная лаборатория

Проект автономного учебного веб-приложения для изучения вероятностей конечной колоды карт и проверяемых математических моделей Blackjack.

**Только виртуальные условные единицы.** Без денежных ставок, игровых аккаунтов и подключений к казино.

Исходники PWA v3.4 будут подготовлены в отдельной ветке и предложены на проверку через Pull Request.
