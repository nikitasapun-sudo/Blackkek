# Blackjack Omega II v3.25 — тренажёр на 8 колодах

Независимые учебные раздачи. Каждая задача начинается со свежих **8 колод (416 карт)**. Для расчёта удаляются только две карты игрока и открытая карта дилера этой задачи. Прошлые раздачи не накапливаются.

В приложении нет учёта вышедших карт, остатка башмака, Running Count, True Count, проникновения, aggregate edge или рекомендаций по размеру ставки. Математическое ядро прежних версий сохранено без изменений; его дополнительные API остаются покрыты регрессиями.

## Как тренироваться

1. Откройте приложение: подсказка для первой задачи появится автоматически.
2. Нажмите «Новая задача» или выберите свои две карты и upcard дилера.
3. По желанию выберите действие и нажмите «Проверить». Ответ не требуется для показа подсказки.
4. Правила доступны в свёрнутом разделе: S17/H17, peek, Charlie, surrender, DOUBLE, выплаты и SPLIT.

Случайная задача выбирается из восьми учебных примеров; это не симуляция случайного порядка всего набора карт. При ручном выборе доступны все 13 рангов.

Для пары подсказка сначала сравнивает обычные действия. Кнопка «Сравнить SPLIT» отдельно запускает точный полный SPLIT либо resplit до выбранных 3–4 рук. После успешного расчёта SPLIT участвует в сравнении. Если расчёт не завершён, его EV не показывается, а область обычной подсказки явно указана.

Каждая попытка учитывается один раз. Сохраняются только настройки и статистика попыток. Задачи между вкладками независимы; изменение правил обновляет подсказку в другой вкладке. Счётчики попыток в браузерах с Web Locks обновляются под общей блокировкой. Старые записи карт прежней версии не читаются, не импортируются и не удаляются.

## Точность и ограничения

- Сохраняется конечная модель 8 колод: внутри раздачи карты извлекаются без возвращения; скрытая карта дилера неизвестна. Это не бесконечная колода и не Monte Carlo.
- «Без peek» означает уже выданную скрытую карту, а не European no-hole-card.
- Ранняя сдача с успешным peek отклоняется как несопоставимое состояние правил.
- Полный SPLIT учитывает общий остаток всех рук и одного дилера; A+10 после разделения не получает выплату за natural.
- Для resplit десяток при `sameRank` ядро требует выбрать `sameValue`, поскольку 10/J/Q/K объединены в один bucket.
- Тяжёлый SPLIT/resplit может превысить время или ресурсы; неполный результат не выдаётся за exact. Подсказка обычных действий не означает, что SPLIT хуже.
- JavaScript Number использует конечную точность. Oracle проверяют конкретные состояния с числовыми допусками, не все возможные комбинации правил.

## Запуск и PWA

Статическое приложение без npm-зависимостей. Можно открыть `index.html` как локальный файл для обычных подсказок. Worker, отдельный SPLIT и установка PWA доступны при запуске через HTTPS или localhost:

```sh
python3 -m http.server 8765 --bind 127.0.0.1
```

После первой онлайн-загрузки интерфейс, Worker и ядро работают офлайн. Адрес GitHub Pages: https://nikitasapun-sudo.github.io/Blackkek/. Публикация выполняется GitHub Actions после слияния в `main`. Выпуск использует кэш `omega-ii-v325-1`.

Ссылка «Проверить обновление» ведёт на `update.html`; восстановление устаревшего HTML и обновление PWA сохраняют настройки и старые данные сайта. При смене версии незавершённый расчёт прекращается, старые результаты очищаются, предлагается открыть новую версию.

## Проверки

Все `.js` и `.cjs` проверяются через `node --check`. Математические тесты, включая `v34`, `depleted_oracle`, `full_split_oracle`, `resplit_exact_oracle`, `resplit_joint_moment_oracle`, `variance_oracle` и независимые Julius oracle, сохранены.

UI-тесты проверяют свежие 8 колод каждой задачи, немедленную подсказку, необязательность ответа, отмену Worker, сохранение настроек, ошибки хранилища и отсутствие учёта башмака. `strategy_edge` и `variance_oracle` проверяют API ядра; эти функции не показаны в тренажёре.

```sh
node tests/v34.cjs
node tests/strategy_trainer.cjs
node tests/ui_state_consistency.cjs
node tests/worker_watchdog.cjs
node tests/integrity.cjs
node tests/pwa_offline.cjs
node tests/update_recovery.cjs
```

GitHub CI выполняет полный набор и реальные Chromium-проверки offline, upgrade, recovery, storage и нескольких вкладок. Для локального браузерного прогона разработчику нужны Playwright и Chromium; установленная PWA этих зависимостей не требует.
